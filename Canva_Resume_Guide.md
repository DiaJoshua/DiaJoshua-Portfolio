# Canva Resume Guide

## When to use which version

- **Job portals & ATS** (JobStreet, LinkedIn Easy Apply, Workday, company career sites): use `Joshua_Dia_Resume_2026.pdf` — it's built to parse cleanly. Canva PDFs sometimes parse badly in ATS.
- **Humans** (email to a hiring manager, referrals, job fairs): use `Joshua_Dia_Resume_Creative.pdf` (designed version, same content) or build your own in Canva with the spec below.

## Finding a template in Canva

Search: **"ATS resume"**, **"minimalist professional resume"**, or **"simple corporate resume"**. Pick only templates that pass ALL of these:

- Single column, top to bottom (no sidebar)
- No photo, no icons next to contact info, no skill bars/star ratings
- Real text everywhere (headers aren't images)
- Black/dark text on white, one accent color max

Two-column designs with photos look nice but get mangled by parsers and waste space you need for bullets.

## Design spec (mirrors your docx)

| Element | Spec |
|---|---|
| Fonts | Lato, Inter, Open Sans, or Source Sans Pro (all in Canva) — one family only |
| Name | 24–28pt, bold, navy |
| Contact line | 9–10pt, gray |
| Section headers | 11pt, bold, ALL CAPS, navy, thin line underneath |
| Body/bullets | 10–10.5pt, line spacing 1.15 |
| Accent color | Navy `#1F3864` (or charcoal `#333333`) — nothing brighter |
| Margins | 1.5–2 cm all sides, strictly 1 page |

## Content

Copy text section-by-section from `Joshua_Dia_Resume_2026.docx` in the same order: Summary → Experience → Projects → Education → Skills → Certifications. Don't rewrite while pasting — one source of truth.

## Photo?

- ATS / multinationals / anything online: **no photo** (also avoids bias filtering; most parsers choke on it).
- Some local PH employers still expect one — if a posting explicitly asks, make a second Canva version with a plain-background corporate headshot (not the graduation photo).

## Export

Share → Download → **PDF Standard** (not PDF Print — smaller file, portals reject >2MB sometimes). Filename: `DIA_Joshua_Resume.pdf`.

## What was wrong with the old design (avoid repeating)

- Two-column layout + photo → ATS parsing problems
- Facebook link → replaced with LinkedIn + GitHub
- "Past few years in tech" claim → reads inflated for a 2025 grad; new summary leads with Trend Micro instead
- Trend Micro job missing entirely → it's now the centerpiece
- Duplicate skills (MongoDB twice), typo "ofthe" → fixed
- Certificates without issuer/year → placeholders added, fill them in
